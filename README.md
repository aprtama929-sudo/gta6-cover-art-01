Panel Pop is an offline cover-art maker that turns a photo and a caption into multi-panel, GTA-style cover art, exported as a PNG. Pick from six panel layouts (Poster, Strips, Trio, Quad, Duo, Solo) with cream gutters and a dark poster frame, fill each panel with your own photo or the bundled samples, and fine-tune every panel's crop by dragging on the canvas, scrolling to zoom, or using the Zoom / Shift sliders. Five Vice City colour grades (Vice Sunset, Neon Nights, Midnight, Golden Hour, Clean) are applied per-pixel, with Brightness / Contrast / Saturation sliders on top. The caption is chunky auto-fitted lettering with a heavy outline and a white, sunset, neon or gold fill; a letter-spaced subtitle sits on a pill near the bottom, and a ringed medallion badge with your own short text marks the corner. Empty panels draw a striped neon-sun placeholder. Export at 1080×1080, 1080×1350, 1920×1080 or 1080×1920. Everything runs locally in the browser — no libraries, no network requests, and photos never leave the machine. All artwork, lettering and decoration are original canvas work.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
